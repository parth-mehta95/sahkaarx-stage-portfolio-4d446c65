# Practice Merging Workflows

## Task Brief
Merge feature branches into develop branch and create release branch demonstrating full Git workflow.

## Scenario
Your team is preparing a release. Merge feature branches into develop, then create and merge a release branch to main.

## Deliverables
- Merged develop branch with features
- Release branch created and merged
- Merge commit history documented

## Success Criteria
- All feature branches successfully merged
- Release branch follows semantic versioning
- No unresolved conflicts in merge history
