# Practice Conflict Resolution

## Task Brief
Simulate and resolve merge conflicts between feature branches to master collaborative workflows.

## Scenario
Two team members modified the same file. Resolve the merge conflict and document the resolution process.

## Deliverables
- Resolved merge conflict in repository
- Documented conflict resolution steps
- Clean commit history

## Success Criteria
- Conflict markers removed and code functional
- Resolution committed with clear message
- Both changes integrated appropriately
