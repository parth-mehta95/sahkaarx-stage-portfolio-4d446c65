# Practice Conflict Resolution Simulation

## Task Brief
Simulate and resolve merge conflicts between feature branches to master collaborative workflows.

## Scenario
Two team members modified the same file in different branches. Resolve merge conflicts and document the resolution process.

## Deliverables
- Resolved merge conflict in repository
- Documented conflict resolution steps
- Clean commit history after merge

## Success Criteria
- Merge conflict successfully resolved
- Resolution documented in commit message
- Main branch reflects both changes correctly
