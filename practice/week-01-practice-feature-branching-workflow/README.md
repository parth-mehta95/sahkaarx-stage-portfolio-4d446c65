# Practice Feature Branching Workflow

## Task Brief
Implement feature branches in your ML project repository and practice branch creation, naming, and management.

## Scenario
Extend ML repository with multiple feature branches following Git workflow best practices and naming conventions.

## Deliverables
- Multiple feature branches created
- Branch naming conventions documented
- Branch management workflow demonstrated

## Success Criteria
- Feature branches follow naming convention
- Branches are properly tracked and organized
- Clear separation of concerns per branch
